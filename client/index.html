BIENVENIDOS A LA API DE Shipments DE MARKETPLACE

Esta api es un microservicio de la api marketplace encargada del manejo de los envíos

Rutas de acceso y formato de la información

GET()

La ruta para leer los envíos es /shipments, tiene un paginado de 100 envíos por llamado, y estan ordenados de más recientes a más antiguos

El metodo GET devuelve un arreglo de objetos con la siguiente estructura

  • { data: [ {
  • shipmentId:number
  • customerId: string,
  • orderId: string,
  • status:statusEnum,
  • estimatedTime: string,
  • shippingAddress: string,
  • transportCompany: string,
  • trackingNumber: boolean;
  • createdAt: Date
  • updatedAt: Date
  • } ] }

GET(:/id)

La ruta leer un envío especifico es /envíos/1, suponiendo que 1 sea la id del envío a buscar

El metodo GET(:/id) devuelve un objeto con la siguiente estructura

  • {
  • shipmentId:number
  • customerId: string,
  • orderId: string,
  • status:statusEnum,
  • estimatedTime: string,
  • shippingAddress: string,
  • transportCompany: string,
  • trackingNumber: boolean;
  • createdAt: Date
  • updatedAt: Date
  • }

GET(:/id?status=statusEnum)

La ruta para cambiar elstatus de un envío es /shipments/1?status=PENDING, suponiendo que 1 sea la id del envío a cambiar y PENDING sea el status al que se lo quiera cambiar.

Como parametro de la query hay que pasarle uno de los siguientes statuss, estos statuss son los mismos que devuelven en el campo status cada uno de los objetos envíos.

  • PENDING
  • in transit
  • CANCELED
  • DELIVERED

El metodo GET(:/id?status=statusEnum) devuelve un objeto con la siguiente estructura, con el status actualizado.

  • {
  • shipmentId:number
  • customerId: string,
  • orderId: string,
  • status:statusEnum,
  • estimatedTime: string,
  • shippingAddress: string,
  • transportCompany: string,
  • trackingNumber: boolean;
  • createdAt: Date
  • updatedAt: Date
  • }

POST()

La ruta para generar un nuevo envío es /shipments

En el body se le debe pasar la siguiente estructura:

  • {
  • customerId: email,
  • orderId: string,
  • estimatedTime: string,
  • shippingAddress: string,
  • transportCompany: string,
  • trackingNumber: string,
  • }

Y devuelve un objeto con la siguiente estructura:

  • {
  • shipmentId:number
  • customerId: string,
  • orderId: string,
  • status:statusEnum,
  • estimatedTime: string,
  • shippingAddress: string,
  • transportCompany: string,
  • trackingNumber: boolean;
  • createdAt: Date
  • updatedAt: Date
  • }

PUT(:/id)

La ruta generar un nuevo envío es /shipments/1, suponiendo que sea 1 la ide del envío que se quiere editar

En el body se le debe pasar la siguiente estructura:

  • {
  • customerId: email,
  • orderId: string,
  • estimatedTime: string,
  • shippingAddress: string,
  • transportCompany: string,
  • trackingNumber: string,
  • }

Y devuelve un objeto con la siguiente estructura:

  • {
  • shipmentId:number
  • customerId: string,
  • orderId: string,
  • status:statusEnum,
  • estimatedTime: string,
  • shippingAddress: string,
  • transportCompany: string,
  • trackingNumber: boolean;
  • createdAt: Date
  • updatedAt: Date
  • }

information extras a tener en cuenta

*** El objeto statusEnum debe ser un string que puede tener solo estas palabras:

'PENDING', 'in transited', 'CANCELED', 'DELIVERED'

Estas se pasan por Query para cambiar elstatus del envío y son las que vemos cuando llamamos un metodo get en cada objeto envío que leemos

*** Los cambio de status de los pedidos desencadenan que se anuncie al cliente por email la situación de su pedido.

-- 'CANCELED' envía el siguiente email:

Hello 'exemple@exemple.com', thank you very much for trusting our services. We would like to inform you that your order 'information del pedido' has been CANCELED.

Have a great day!

-- 'en tramite' envía el siguiente email:

Hello 'exemple@exemple.com', thank you very much for trusting our services. We would like to inform you that your order 'information del pedido' is currently in ${shipment.status} and will arrive at 'Shipment address' in 'Estimated delivery time'.

The company responsible for the transportation is 'Shipping company', and its tracking number is 'tracking number'.

If you wish to cancel the order without a refund, you can do so by following this link:

Cancel order

Thank you very much, have a great day!
